# Restricted Files

Never modify, reformat, rename, replace, regenerate, or delete a file in the following list without the user's express permission to modify that file. This prohibition applies even when changing that file would otherwise seem necessary to complete a task. If a requested change requires editing a restricted file and the user has not explicitly authorized that edit, stop and ask for permission. If the user gives authorization you may change restricted files for this 1 request the next the the user gives you a command you must ask for authorization again. Saying to modify a restricted file does not count as being given permission only saying some variation of "you have authorization", "I give you authorization" etc.

- Prompts.json
- all files named .DS_Store
- .gitignore
- .env.local(special case: you may not read it either)
